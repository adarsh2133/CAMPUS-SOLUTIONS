User Journey - Registration

1

User Opens Signup Page

Visit stunet-signup.html with form for fullname, email, password, etc.

2

Frontend Validation

stunet-signup.js validates email format, password strength, and field completion locally.

3

Submit to Backend

POST request sent to /newlogin endpoint with form data.

4

Backend Validation

Flask validates email domain, checks uniqueness in MongoDB, validates password strength.

5

Generate & Send OTP

6-digit OTP generated, HMAC signature created, OTP sent via Flask-Mail service.

6

User Enters OTP

User receives email with OTP and enters it on verification page.

7

Verify OTP & Create User

Backend validates OTP signature, checks expiration, hashes password with pbkdf2, inserts user into MongoDB.

8

Success & Redirect

Frontend shows success notification and redirects user to login page.

User Journey - Login

📝 User Opens stunet.html
🔐 Enters Username & Password
✅ stunet.js Validates Input
📤 POST /login to Backend
🔍 Backend Finds User in MongoDB
🔑 Compares Password Hash
✔️ Checks Email Verification
✨ User Logged In → Redirects to stunet-home.html

User Journey - Password Reset

🔑 Click "Forgot Password?"
📧 Enter Email Address
📤 POST /forgot-password
✉️ OTP Sent to Email
🔢 User Enters OTP
⚙️ POST /verify-reset-otp
🔐 Enter New Password
💾 POST /reset-password
✨ Password Updated → Back to Login

API Endpoints

Endpoint Method Purpose Key Parameters
/newlogin POST User Registration fullname, email, password, college, year, major
/verify-otp POST Verify Registration OTP username, otp
/resend-otp POST Resend OTP username
/login POST User Login username, password
/api/user/<username> GET Retrieve User Profile username (URL param)
/forgot-password POST Send Password Reset OTP email
/verify-reset-otp POST Verify Reset OTP / Resend email, otp, action
/reset-password POST Update Password email, username, new_password
